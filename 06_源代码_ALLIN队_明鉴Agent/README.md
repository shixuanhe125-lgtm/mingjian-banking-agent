# 明鉴 Agent：可解释安全银行

ALL IN队 · 中央财经大学 · 石轩赫

这是可直接运行的本地银行 AI Agent 竞赛原型。用户用自然语言提出需求，Qwen3-1.7B 本地大模型生成候选任务；白名单工具、参数校验、权限引擎和授权状态机在模型之外独立控制执行。账户、账单、转账和订阅均为合成的竞赛沙箱数据，不连接真实银行、也不处理真实资金。

## 直接使用

Windows 用户双击 `启动明鉴Agent.cmd`。启动器会启动本地 Qwen 模型、启动银行沙箱，并自动打开 `http://127.0.0.1:8787/`。使用完双击 `停止明鉴Agent.cmd`。若浏览器没有自动打开，可双击 `打开明鉴.html`。

完整产品包已经携带 Node.js、llama.cpp 和模型权重，无需购买 API；源码轻量包首次启动时需要联网下载固定版本模型。

## 推荐演示路径

1. 输入“先看看我手头还有多少，再给室友打两百块”。观察真实模型耗时、任务 DAG、绿色查询自动执行和黄色转账等待授权。
2. 点“修改参数”，将收款人改为李四、金额改为 1200 元。查看新旧参数、余额变化、风险升级，旧授权自动失效。
3. 在“安全设置”中用手机身份验证器手工录入密钥并填写 6 位动态码。等待下一周期动态码后完成红色操作验证。
4. 输入“帮我看看这个月的钱都花到哪里了，有没有重复扣费”。查看工具依据合成明细生成的分类统计和证据引用。
5. 输入“我有哪些会员在扣钱？把视频那个停掉”。审阅并确认取消操作。
6. 输入“给妈妈转点钱”，再回答“就一千二百元吧”，演示跨轮澄清。

## 产品能力与边界

- 已实现真实本地大模型意图理解、余额查询、本月账单分析、即时联系人转账、订阅查询/取消、顺序 DAG、中断/恢复/取消/人工接管、授权差异检视、哈希审计链、异常熔断和 TOTP 手机动态码。
- 绿色操作自动执行；黄色操作需明确审阅确认；红色操作需明确确认和手机 TOTP。
- 模型只提交结构化候选动作。服务端会去重、重新验证收款人、金额和依赖关系，并在提交瞬间重算余额与日累计额度。
- 未实现真实银行 API、生产身份登录、短信/人脸/U盾、理财、卡片、定时转账和 AA 收款。网页中的资金与回执都是可验证的本地模拟数据。
- TOTP 密钥存放在本地 SQLite，适用于竞赛演示，不等同于银行生产级密钥托管。

## 架构

```text
浏览器对话 + 透明任务单
        │
本机 HTTP（Origin / CSRF / Session）
        │
Qwen3-1.7B 候选规划 → JSON Schema
        │
白名单工具 + DAG 校验 + 参数校验
        │
绿色自动 / 黄色确认 / 红色 TOTP
        │
SQLite 原子账本 + 幂等回执 + 哈希审计链
```

主要代码：`src/agent.mjs` 是真实大模型适配与结构化规划，`src/bank.mjs` 是独立策略及执行状态机，`src/totp.mjs` 是 RFC 6238 动态码，`server.mjs` 是本机 API，`public/` 是免构建网页。

## 数据重置

先运行停止脚本，再把 `data` 文件夹重命名为备份，重新启动即可生成新的模拟账本。不要在进程运行时修改 SQLite 文件。

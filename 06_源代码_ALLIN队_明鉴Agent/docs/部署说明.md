# 一、直接运行完整版

解压“07_可运行完整版_ALLIN队_明鉴Agent.zip”，双击“启动明鉴Agent.cmd”。启动器会加载本地模型并自动打开 http://127.0.0.1:8787/。首次加载通常需要5—30秒。使用完双击“停止明鉴Agent.cmd”。

完整版自带 Node.js 24、llama.cpp 和 Qwen3-1.7B Q8_0，不需要付费API。程序只监听本机地址。请至少保留约4GB磁盘空间和8GB内存；推荐16GB内存。

# 二、运行源码轻量包

轻量包不含约1.8GB模型权重。Windows首次双击启动器时，setup-local-model.ps1 会从官方固定地址下载模型与执行引擎并校验 SHA-256。下载完成后可离线运行。若网络无法访问，可使用完整版。

# 三、安全设置

红色操作前进入“安全设置”，在手机身份验证器中选择手工输入密钥，填写页面显示的32位密钥，再输入手机当前6位动态码完成绑定。绑定码不可立即重用于转账，等待下一个30秒周期后再验证。请勿用真实银行密码或验证码。

# 四、测试复现

运行 runtime\node.exe --test，应显示39项通过。启动模型后运行 runtime\node.exe scripts\verify-live-agent.mjs，应显示6个场景 passed:true。测试使用内存数据库，不改变正式演示账户。

# 五、数据与故障排查

数据位于 data/bank.sqlite。重置时先停止服务，把data目录改名备份，再重新启动。日志位于.build/model-error.log和.build/server-error.log。端口8790或8787被占用时先关闭冲突程序。不要在进程运行中替换数据库。
